# 项目章程

## 1. 项目目标

独立建设一套“零推荐职位激活系统”，帮助企业 HR/猎头发现长期没有候选人推荐的职位，利用授权数据源完成候选人匹配、触达、意向收集和推荐闭环。

对方招聘网站和 MCP 是外部数据能力，不是本项目的业务系统。本项目必须通过适配层降低对单一供应方的耦合。

## 2. 用户与角色

MVP 的管理端只服务内部运营、内部 HR/猎头和管理员。企业客户自助门户、多租户配置与计费不在首版范围；候选人仅使用脱敏职位落地页。

| 角色 | 核心诉求 | MVP 权限 |
|---|---|---|
| 招聘运营 | 找到沉睡职位并批量激活 | 查看职位、匹配、活动与漏斗 |
| HR/猎头 | 获得可跟进的合适人选 | 审核匹配、查看候选人、标记推荐 |
| 候选人 | 安全了解机会并表达意向 | 查看脱敏落地页、选择意向、提交联系方式 |
| 管理员 | 管理接入、权限和审计 | 用户、配置、审计和数据治理 |

## 3. 成功指标

第一阶段不承诺图中漏斗的固定转化率，以真实数据建立基线。建议跟踪：

- 沉睡职位发现数量与有效率。
- 每个职位的候选人匹配数量及人工通过率。
- 发送成功率、点击率、落地页完成率和“有兴趣”率。
- 从职位发现到首位候选人推荐的耗时。
- 每个职位最终推荐人数。
- 退订率、投诉率和无效联系方式比例。

## 4. MVP 范围

- 通过 MCP、授权 Web 采集或授权导入获取沉睡职位和候选人；外部来源均经适配器接入。
- 统一清洗、去重、存储并生成不超过 150 字的摘要。
- 基于硬性条件、关键词和可配置权重计算本地可复算匹配分；供应方分数仅作外部对照。
- 为匹配结果生成可解释理由，并提供人工审核。
- 生成带访问令牌的脱敏职位落地页。
- 生成短信（不超过 70 个中文字符或按渠道计费规则校验）和邮件草稿。
- 对接一个短信或邮件渠道，或在渠道未定时支持导出发送清单。
- 记录完整漏斗事件并提供基础看板。
- 支持人工确认并登记最终推荐结果。

## 5. 暂不纳入 MVP

- 自动机器人外呼与通话质检。
- 无人工审核的全自动群发和全自动推荐。
- 复杂向量检索、模型微调和自研推荐算法。
- 多租户计费、复杂组织架构和完整 CRM。
- 企业客户自助登录、职位发布和客户侧运营后台。
- 将生产部署绑定到某个指定云平台。

## 6. 外部依赖

- 招聘网站账号及允许使用的功能范围。
- MCP 测试/生产凭证和接口文档。
- 供应方 Web 平台账号、自动化采集范围、频率、字段、用途、保留和删除要求。
- 职位、简历数据的存储和触达授权。
- 短信/邮件渠道账号、模板审核和签名。
- 域名、SSL、部署环境和数据保存区域的最终决策。
